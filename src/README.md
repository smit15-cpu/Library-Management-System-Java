# Library Management System (Java + MySQL)

## Features
- Add Book (with validation)
- View all books
- Issue book
- Return book
- Search book by ID
- MySQL database integration
- JDBC connectivity

## Tech Stack
- Java
- MySQL
- JDBC

## Concepts Used
- OOP (Encapsulation)
- CRUD operations
- Database connectivity
- PreparedStatement
- Exception handling
